## What is this repository?

`koppajs-documentation` is the dedicated documentation home for the KoppaJS
ecosystem.

It exists so package repos can stay focused on code and package-local guidance
while broader explanations, guides, and ecosystem-level narratives have a clear
canonical home.

---

## Scope

This repository is intended to hold:

- long-form framework and ecosystem documentation
- cross-package onboarding guides
- conceptual explanations that should not be duplicated across package repos
- a stable public entry point for readers who want documentation first and code
  second

---

## Current Status

The repository is currently intentionally light. It already acts as the
documentation anchor used across the KoppaJS package READMEs, and it can grow
incrementally as package-level docs are consolidated or expanded.

Until more material lands here, the package READMEs and their local meta-layer
documents remain the primary source for package-specific runtime, architecture,
and release details.
