# Roadmap

## 0.1.0 Baseline

The repository now targets an initial pre-`1.0.0` website baseline with:

- a routed KoppaJS application shell
- explicit architecture, testing, and release documentation
- Vitest and Playwright verification
- CI coverage on Node.js 22 and 24

## Next Expansion Areas

- grow the route-level docs beyond the current overview/setup/package/testing
  baseline
- add richer conceptual documentation for the KoppaJS ecosystem without
  duplicating package-local contracts
- expand browser coverage when the site gains more interactive behavior,
  search, examples, or live embeds
