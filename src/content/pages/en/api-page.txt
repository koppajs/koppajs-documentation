          <article class="docs-mini-card">
            <h3>Props definitions</h3>
            <pre class="docs-code"><code>props: {
  name: { type: String, required: true },
  color: { type: String, default: "blue" },
  email: { type: String, regex: "^[a-z]+@[a-z]+\\.[a-z]+$" },

            <ul class="docs-list">
              <li>Supported types: <code>String</code>, <code>Number</code>, <code>Boolean</code>, <code>Array</code>, <code>Object</code>, <code>Function</code>.</li>
              <li>A simple path in a <code>:binding</code> allows two-way binding.</li>
              <li>If there is a type mismatch, an error is logged and the prop is not set.</li>

      <section id="lifecycle" class="docs-section-card docs-section-anchor">
        <p class="docs-eyebrow">Lifecycle</p>
        <h2 class="docs-section-title">Hook order and update semantics.</h2>
        <div class="docs-table-wrap">
          <table class="docs-table">
            <thead>
              <tr>
                <th>Hook</th>
                <th>Time</th>
                <th>Frequency</th>
              </tr>
            </thead>
            <tbody>
              <tr><td><code>created</code></td><td>After script evaluation, before DOM mount</td><td>Once</td></tr>
              <tr><td><code>beforeMount</code></td><td>Before first DOM insertion</td><td>Once</td></tr>
              <tr><td><code>mounted</code></td><td>After first DOM insertion</td><td>Once</td></tr>
              <tr><td><code>processed</code></td><td>After template processing</td><td>With every render</td></tr>
              <tr><td><code>beforeUpdate</code></td><td>Before every re-rendering</td><td>During updates</td></tr>
              <tr><td><code>updated</code></td><td>After every re-rendering</td><td>During updates</td></tr>
              <tr><td><code>beforeDestroy</code></td><td>Before removal</td><td>Once</td></tr>
              <tr><td><code>destroyed</code></td><td>By distance</td><td>Once</td></tr>
            </tbody>
          </table>
        </div>

        <pre class="docs-code"><code>created -&gt; beforeMount -&gt; [processed] -&gt; mounted
               ↓
       beforeUpdate -&gt; [processed] -&gt; updated
               ↓
       beforeDestroy -&gt; destroyed</code></pre>

        <div class="docs-grid-2">
          <article class="docs-mini-card">
            <h3><code>changedPaths</code></h3>
            <p class="docs-text">In <code>beforeUpdate</code> and <code>updated</code>, <code>this.changedPaths</code> is available as <code>Set&lt;string&gt;</code>. It is ephemeral and only lives during the update cycle.</p>
          </article>

          <article class="docs-mini-card">
            <h3><code>beforeUpdate</code> vs <code>updated</code></h3>
            <ul class="docs-list">
              <li>You use <code>beforeUpdate</code> before the new DOM is mounted.</li>
              <li><code>updated</code> is used for focus, measurement or imperative DOM APIs after the update.</li>
              <li>Both hooks see the same <code>changedPaths</code>, but at different times.</li>
            </ul>
          </article>
        </div>

      <section id="limitations" class="docs-section-card docs-section-anchor">
        <p class="docs-eyebrow">restrictions</p>
        <h2 class="docs-section-title">Known limits of the current runtime.</h2>
        <div class="docs-table-wrap">
          <table class="docs-table">
            <thead>
              <tr>
                <th>Limitation</th>
                <th>Explanation</th>
                <th>Workaround</th>
              </tr>
            </thead>
            <tbody>
              <tr><td><code>Date</code> objects in the state</td><td>Proxy breaks native Date methods</td><td>Use timestamps or ISO strings</td></tr>
              <tr><td><code>RegExp</code> in State</td><td>Proxy compatibility issues</td><td>Save regex as string and convert if necessary</td></tr>
              <tr><td>Deeply nested array mutations</td><td><code>items[0].sub.push(x)</code> doesn't always trigger cleanly</td><td>Reassign parent array or use <code>splice</code></td></tr>
              <tr><td>Frozen objects</td><td>Mutation throws an error</td><td>Do not freeze state</td></tr>
              <tr><td>No automatic CSS scoping</td><td>Styles are global</td><td>Use tag names as selector prefix</td></tr>
              <tr><td>Custom element tags</td><td>Must contain a hyphen</td><td>For example <code>my-app</code> instead of <code>myapp</code></td></tr>
              <tr><td>No SSR</td><td>Client side only</td><td>-</td></tr>
            </tbody>
          </table>
        </div>
      </section>
