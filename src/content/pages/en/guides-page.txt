      <section id="konzepte" class="docs-section-card docs-section-anchor">
        <p class="docs-eyebrow">Basic concepts</p>
        <h2 class="docs-section-title">How KoppaJS works.</h2>
        <div class="docs-grid-3">
          <article class="docs-mini-card">
            <h3>Components as Custom Elements</h3>
            <p>Each component is registered as a native custom element. Due to the Web Components standard, the tag name must always contain a hyphen, such as <code>&lt;app-view&gt;&lt;/app-view&gt;</code>.</p>
          </article>
          <article class="docs-mini-card">
            <h3>Register, then boot</h3>
            <p>With <code>Core.take()</code> you register components, plugins or modules. Only <code>Core()</code> starts the framework and mounts registered elements in the DOM.</p>
          </article>
          <article class="docs-mini-card">
            <h3>Reactive proxies</h3>
            <p>The state is automatically wrapped in a proxy. Any mutation can trigger re-rendering without having to manually write DOM patches.</p>
          </article>
        </div>

        <article class="docs-mini-card">
          <h3>Components, plugins and modules</h3>
          <p class="docs-text">Components render UI. Plugins provide app-wide services such as stores or router access via <code>$take("name")</code>. Modules extend components or elements with additional runtime logic.</p>
          <pre class="docs-code"><code>import { Core } from "@koppajs/koppajs-core";
import appView from "./app-view.kpa";
import storePlugin from "./store-plugin";
import routerModule from "./router-module";

Core.take(storePlugin);
Core.take(routerModule);
Core.take(appView, "app-view");
Core();</code></pre>
          <pre class="docs-code"><code>created() {
  const store = $take("store");
  store.loadUser();
},

mounted() {
  this.$router?.navigate("/dashboard");
}</code></pre>
        </article>

        <article class="docs-mini-card">
          <h3>Lifecycle of a KoppaJS app</h3>
          <div class="docs-flow">
            <div class="docs-flow-step">1. <code>main.ts</code> is loaded and imports <code>.kpa</code> files.</div>
            <div class="docs-flow-step">2. <code>Core.take(...)</code> registers components and optional extensions.</div>
            <div class="docs-flow-step">3. <code>Core()</code> starts the app and finds custom elements in the DOM.</div>
            <div class="docs-flow-step">4. Script, props and reactive state are prepared, then <code>created()</code> fires.</div>
            <div class="docs-flow-step">5. The template is processed, events are bound, the DOM is deployed and <code>mounted()</code> runs.</div>
            <div class="docs-flow-step">6. Further state changes trigger automatic updates.</div>
          </div>
        </article>
      </section>
