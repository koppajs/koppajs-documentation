KoppaJS

Pragmatic frontend made modular.

Build fast, simple, and growable – without the noise of modern frameworks.

KoppaJS ist ein leichtgewichtiges, modulares Frontend-Framework auf Basis nativer Web Components. Diese Oberfläche bündelt die vollständige Benutzerdokumentation zu Komponenten, Reaktivität, Templates, Tooling, API und Beispielen in einer einzigen Docs-App.

Quick start

Der schnellste Weg in ein neues Projekt führt über die CLI oder die minimale manuelle Vite-Integration. 

pnpm create koppajs my-app
cd my-app
pnpm install
pnpm dev

Runtime

@koppajs/koppajs-core registriert Komponenten, initialisiert die App und hält reaktiven State mit DOM-Updates synchron.

Tooling

Das offizielle Vite-Plugin kompiliert .kpa-Dateien und hält HMR, Build und TypeScript-Unterstützung zusammen.
