Schnellstart

Vom neuen Projekt zur laufenden KoppaJS-App.

CLI, manuelle Vite-Integration, Projektstruktur und die wichtigsten Scripts in einer zusammenhängenden Startseite.

KoppaJS ist ein leichtgewichtiges, modulares Frontend-Framework auf Basis nativer Web Components. Im Kern kombinierst du @koppajs/koppajs-core mit dem offiziellen Vite-Plugin und optional weiteren Paketen wie create-koppajs oder koppajs-router.

~13.6 kB gzipped Single-File Components TypeScript-First Web Components

Sofort loslegen

pnpm create koppajs my-app
cd my-app
pnpm install
pnpm dev

Einführung

Wofür KoppaJS gedacht ist.

  • Single-File Components: Template, Script und Style in einer .kpa-Datei.
  • Reaktives State Management: Proxy-basierte DOM-Updates bei State-Änderungen.
  • Lifecycle Hooks: created, mounted, updated und mehr.
  • TypeScript-First: erstklassige Unterstützung über [ts]-Blöcke.
  • Vite-Integration: schnelles HMR und Builds über das offizielle Plugin.
Paket Zweck
@koppajs/koppajs-core Runtime-Framework und Kernbibliothek
@koppajs/koppajs-vite-plugin Kompiliert .kpa-Dateien zu JavaScript
create-koppajs CLI zum Erstellen neuer Projekte

CLI

Ein neues Projekt mit create-koppajs erzeugen.

Projekt anlegen

# Mit pnpm (empfohlen)
pnpm create koppajs my-app

# Mit npm
npm create koppajs my-app

# Mit npx
npx create-koppajs my-app

CLI-Optionen

  • --help / -h zeigt die Hilfe an.
  • --version / -v zeigt die Version an.
  • Ohne Projektnamen startet eine interaktive Eingabeaufforderung.
Nach der Projektanlage startest du lokal mit cd my-app, pnpm install und pnpm dev.

Manuelle Einrichtung

KoppaJS in ein bestehendes Vite-Projekt integrieren.

1. Pakete installieren

pnpm add @koppajs/koppajs-core
pnpm add -D @koppajs/koppajs-vite-plugin

2. Vite konfigurieren

import { defineConfig } from "vite";
import koppaPlugin from "@koppajs/koppajs-vite-plugin";

export default defineConfig({
  plugins: [
    koppaPlugin({
      tsconfigFile: "./tsconfig.json",
    }),
  ],
});

3. Entry-Point erstellen

import { Core } from "@koppajs/koppajs-core";

import appView from "./app-view.kpa";

Core.take(appView, "app-view");
Core();

4. HTML-Datei aufsetzen

<!doctype html>
<html lang="de">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Meine KoppaJS App</title>
  </head>
  <body>
    <app-view></app-view>
    <script type="module" src="/src/main.ts"></script>
  </body>
</html>

Projektstruktur

Die minimale Form eines typischen KoppaJS-Projekts. 

my-app/
├── index.html
├── package.json
├── tsconfig.json
├── vite.config.mjs
├── public/
│   └── favicon.svg
└── src/
    ├── main.ts
    ├── style.css
    ├── app-view.kpa
    └── counter-component.kpa

Was wohin gehört?

  • index.html ist das Vite-Entry-HTML.
  • src/main.ts registriert Komponenten und bootet die App.
  • src/style.css hält globale Styles.
  • app-view.kpa ist typischerweise die Root-Komponente.
  • Weitere .kpa-Dateien bilden wiederverwendbare UI-Bausteine.
